💻  Mi Portafolio Personal ✨

Bienvenido al repositorio de mi portafolio personal. Este proyecto es una presentación de mis habilidades, experiencia y logros como Desarrollador de Software Junior.

El portafolio está diseñado para ser responsive, visualmente atractivo y altamente funcional, incluyendo la capacidad de cambiar de idioma (español/inglés) y una navegación fluida.

🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando un stack de desarrollo web fundamental:

    HTML5: Estructura semántica de la página.

    CSS: Estilos, diseño responsive y animaciones.

    JavaScript: Para la interactividad, manejo del idioma y lógica de los modales.
    
Características Clave Implementadas

### Características Clave Implementadas

| Característica | Descripción | Implementación |
| :--- | :--- | :--- |
| **Bilingüe** | Permite cambiar el contenido de la página entre **español** e **inglés** con un solo botón. | **JavaScript** (Manejo de atributos `data-es` y `data-en`) y **`localStorage`** para recordar la preferencia. |
| **Modal de Certificados** | Muestra una vista ampliada de los certificados al hacer clic, con un cierre funcional (botón X, clic fuera). | **JavaScript** (Función `closeModal` y manejo de eventos `click`). |
| **Scroll Dinámico** | Implementación del efecto **Scroll-Reveal** para animar la entrada de secciones a medida que el usuario se desplaza. | **JavaScript** (API `IntersectionObserver`). |
| **Header Dinámico** | La barra de navegación se ajusta y se vuelve fija después de un desplazamiento inicial, mejorando la experiencia de usuario. | **JavaScript** (Manejo del evento `scroll` y clases CSS). |

### 📦 Estructura del Proyecto

El repositorio sigue una estructura estándar para un proyecto web estático:

    .
    ├── assets/
    │   ├── perfil.png             # Foto de perfil
    │   └── certificados/          # Carpeta con las imágenes de los certificados
    ├── index.html                 # La estructura principal del portafolio.
    ├── styles.css                 # Todos los estilos de la aplicación.
    └── script.js                  # Toda la lógica de la página (idioma, scroll, modal, header).
